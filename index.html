Flow 1 – Kaart Ontgrendelen / Niet Ontvangen
🔵 1. START
Mail komt binnen
Onderwerp: "Kaart kan niet ontgrendeld worden"
🟡 2. CHECK CONTENT
Controleer aanwezigheid:
  • ✓ E-mailadres ontvanger
  • ✓ Giffy code
  • ✓ Gekozen brand (Bol/Zalando)
➜ ❌ Info ontbreekt
Vraag ontbrekende gegevens op → Wacht → Terug naar stap 2
➜ ✅ Alles compleet
Ga naar stap 3
🟡 3. CHECK MANDRILL
Zoek e-mailadres in Mandrill
➜ ❌ Email bestaat niet
Escalatie → Check WooCommerce
➜ ✅ Email bestaat
Check status →
🟡 4. MANDRILL STATUS
➜ 🟢 GROEN
Mail opnieuw verzenden → Ga naar AFRONDING
➜ 🔴 ROOD
Ga naar stap 5
🔵 5. CHECK WOOCOMMERCE
Zoek op Giffy-code
➜ 🟢 Status = OK
Mail opnieuw verzenden → AFRONDING
➜ 🔴 Status = FAILED
Klik order link → Bekijk product →
🟡 6. PRODUCT CHECK
WooCommerce → Alle producten → Product ID
  • Product ID waarden
  • Product EN-codes
➜ ❌ Niet correct
Escaleer naar Irena OF Kaartleverancier
➜ ✅ Wel correct
Technische issue → Escaleer
🟢 AFRONDING
Sluit case in Intercom
  • Klantnaam toevoegen
  • Status: Opgelost/Escalatie
  • Interne note
✅ FLOW EINDIGT
Flow 2 – Haskoning Special Flow
🔵 1. START
Mail binnen van Haskoning
(Kunnen niet online zelf bestellen)
🟡 2. CHECK INFO
Mail moet bevatten:
  • Giftcode
  • Gewenste kaart
  • Waarde
➜ ❌ Info ontbreekt
Vraag op via Intercom/email
➜ ✅ Info compleet
Ga naar stap 3
🟡 3. CHECK TRADE PORTAL
Giffy Portal: Heeft code juiste waarde?
➜ ❌ Klopt niet
Escalatie (technisch)
➜ ✅ Klopt wel
Ga naar stap 4
🔵 4. BLOKKEER KAART
Kaart blokkeren in systeem
🔵 5. GO GIFT SHEET
Handmatig invullen:
  • Brand (Bol.com)
  • Waarde (€)
  • Code (Giffy)
🔵 6. INTERCOM UPDATE
Hashtag toevoegen:
#kaart-komt-eraan
🔵 7. EIND VAN DAG
Auto-verzending via GoGift OF Bamboe Portal
🟢 AFRONDING
Sluit case in Intercom
  • Status: Verzonden
  • Interne notitie
✅ FLOW EINDIGT
Flow 3 – Kaart Wijzigen / Annuleren
🔵 1. START
Mail binnen:
"Kaart per ongeluk gekozen / niet meer gewenst"
🟡 2. CHECK ONTGRENDELING
Is kaart al ontgrendeld?
➜ ✅ ONTGRENDELD
❌ Geen wijziging mogelijk → Informeer klant → EINDE
➜ ❌ NIET ONTGRENDELD
✅ Wijziging mogelijk → Ga naar stap 3
🔵 3. CONTACT CEES
Verzoek: Team Coda blokkeer ontgrendelmail
  • Verstrek Giffy code
  • Verstrek klantgegevens
🟡 4. BEVESTIG BLOKKERING
Wacht op bevestiging Cees
➜ ⏳ Nog niet geblokkeerd
Wachten...
➜ ✅ Geblokkeerd
Ga naar stap 5
🔵 5. KIES OPLOSSING
Bespreek met klant:
  • Optie 1: Nieuwe kaart versturen
  • OF
  • Optie 2: Restitutie via Benify
🟢 AFRONDING
Sluit case in Intercom
  • Status: Omgezet/Terugbetaald
  • Interne notitie
  • Gekozen oplossing
✅ FLOW EINDIGT
Flow 4 – Direct Gekochte Kaart Niet Ontvangen
🔵 1. START
Mail/telefoontje binnen:
"Direct gekochte kaart niet ontvangen"
  • Kanaal: Benify (IKEA) of KPN Voor Jou
  • Betaling via: Adyen
🟡 2. VERZAMEL KLANTGEGEVENS
Vraag naar klant:
  • ✓ Voornaam
  • ✓ Bedrag van aankoop (€)
  • ✓ Datum van aankoop
➜ ❌ Gegevens ontbreken
Vraag ontbrekende info op → Wacht → Terug naar stap 2
➜ ✅ Gegevens compleet
Ga naar stap 3
🔵 3. CHECK ADYEN TRANSACTIE
Open Adyen Dashboard
  • Ga naar "Transacties" / "Payments"
  • Zoek op voornaam
  • Filter op datum en bedrag (indien nodig)
🟡 4. CONTROLEER BETALINGSSTATUS
Bekijk status van de transactie
➜ 🔴 Status = NIET GOEDGEKEURD
(Refused/Failed/Cancelled)
→ Card issue / Betaling mislukt
→ Informeer klant: "Je betaling is niet doorgekomen"
→ Advies: Check bij bank of probeer andere betaalmethode
→ Ga naar AFRONDING
➜ 🟢 Status = GOEDGEKEURD
(Authorised/Captured)
→ Betaling is OK, probleem zit bij verzending
→ Ga naar stap 5
🟡 5. CHECK KLANT TYPE
Welke klant is het?
➜ IKEA (Benify)
Ga naar stap 6 - IKEA Landcheck
➜ KPN Voor Jou OF Andere
Ga naar Flow 1 (Standaard niet ontvangen)
→ Check Mandrill → WooCommerce → etc.
🟡 6. IKEA LANDCHECK
(Alleen voor IKEA klanten)
Welk IKEA land?
➜ IKEA Sweden / Denmark
Platform: GoGift Portal
→ Ga naar stap 7a
➜ IKEA Netherlands (NL)
Platform: Trade Portal
→ Ga naar stap 7b
🔵 7A. GOGIFT PORTAL CHECK
(Voor IKEA SE/DK)
  • Open GoGift Portal
  • Zoek op email adres of order referentie
  • Check: Is de unlock email verzonden?
➜ 🟢 Email verzonden
→ Kaart moet in inbox staan
→ Check met klant: Spam folder?
→ Zo ja: Email opnieuw verzenden
→ Ga naar AFRONDING
➜ 🔴 Email NIET verzonden
→ Technisch probleem
→ Escaleer naar GoGift support
→ Ga naar AFRONDING
🔵 7B. TRADE PORTAL CHECK
(Voor IKEA NL)
  • Open Trade Portal (Giffy)
  • Zoek op email adres of code
  • Check: Is de unlock email verzonden?
➜ 🟢 Email verzonden
→ Kaart moet in inbox staan
→ Check met klant: Spam folder?
→ Zo ja: Email opnieuw verzenden via Trade
→ Ga naar AFRONDING
➜ 🔴 Email NIET verzonden
→ Technisch probleem
→ Check order status in Trade
→ Indien nodig: handmatig versturen
→ Ga naar AFRONDING
🟢 AFRONDING
Sluit case in Intercom
  • Klantnaam toevoegen
  • Status: Opgelost / Card Issue / Escalatie
  • Kanaal: IKEA / KPN
  • Actie: Email verzonden / Betaling mislukt / Geëscaleerd
  • Interne notitie
✅ FLOW EINDIGT
🔵 Actie - Uitvoeren door support
🟡 Check - Controleren / Beslissen
🔴 Escalatie - Doorsturen
🟢 Afronding - Case sluiten
