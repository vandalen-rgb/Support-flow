Flow 1 – Kaart Ontgrendelen / Niet Ontvangen
🟢 1. START 1e lijn
Mail komt binnen
Onderwerp: "Kaart kan niet ontgrendeld worden"
🟢 2. VRAAG NAAR GEGEVENS EN ZET IN INTERCOM 1e lijn
Verzamel en registreer:
  • ✓ E-mailadres ontvanger
  • ✓ Giffy code
  • ✓ Gekozen brand (Bol/Zalando)
➜ ❌ Info ontbreekt
Vraag ontbrekende gegevens op
➜ ✅ Alles compleet
→ Zet in Intercom
→ Bevestig klant: "We nemen binnen 1 uur contact op via [email]"
→ EINDE 1E LIJN
⚡ OVERDRACHT 1E → 2E LIJN
1e lijn (Joy/Nelson): Ticket aangemaakt in Intercom
2e lijn: Pakt ticket op en vervolgt hieronder →
🔵 3. CHECK MANDRILL 2e lijn
Zoek e-mailadres in Mandrill
➜ ❌ Email bestaat niet
Escalatie → Check WooCommerce
➜ ✅ Email bestaat
Check status →
🔵 4. MANDRILL STATUS 2e lijn
➜ 🟢 GROEN
Mail opnieuw verzenden → Ga naar AFRONDING
➜ 🔴 ROOD
Ga naar stap 5
🔵 5. CHECK WOOCOMMERCE 2e lijn
Zoek op Giffy-code
➜ 🟢 Status = OK
Mail opnieuw verzenden → AFRONDING
➜ 🔴 Status = FAILED
Klik order link → Bekijk product →
🔵 6. PRODUCT CHECK 2e lijn
WooCommerce → Alle producten → Product ID
  • Product ID waarden
  • Product EN-codes
➜ ❌ Niet correct
Escaleer naar Irena OF Kaartleverancier
➜ ✅ Wel correct
Technische issue → Escaleer
🟢 AFRONDING
Sluit case in Intercom
  • Klantnaam toevoegen
  • Status: Opgelost/Escalatie
  • Interne note
✅ FLOW EINDIGT
Flow 2 – Direct Gekochte Kaart Niet Ontvangen
🟢 1. START 1e lijn
Mail/telefoontje binnen:
"Direct gekochte kaart niet ontvangen"
  • Kanaal: Benify (IKEA) of KPN Voor Jou
  • Betaling via: Adyen
🟢 2. VERZAMEL KLANTGEGEVENS EN EMAIL 1e lijn
Vraag naar klant:
  • ✓ Voornaam
  • ✓ Email adres
  • ✓ Bedrag van aankoop (€)
  • ✓ Datum van aankoop
➜ ❌ Gegevens ontbreken
Vraag ontbrekende info op
➜ ✅ Gegevens compleet
Ga naar stap 3
🟢 3. CHECK ADYEN TRANSACTIE 1e lijn
Open Adyen Dashboard
  • Ga naar "Transacties" / "Payments"
  • Zoek op voornaam
  • Filter op datum en bedrag (indien nodig)
🟢 4. CONTROLEER BETALINGSSTATUS 1e lijn
Bekijk status van de transactie
➜ 🔴 Status = NIET GOEDGEKEURD
(Refused/Failed/Cancelled)
→ Card issue / Betaling mislukt
→ Informeer klant: "Je betaling is niet doorgekomen"
→ Advies: Check bij bank of probeer andere betaalmethode
→ EINDE 1E LIJN - Ga naar AFRONDING
➜ 🟢 Status = GOEDGEKEURD
(Authorised/Captured)
→ Betaling is OK
→ Zet in Intercom
→ Bevestig klant: "We nemen binnen 1 uur contact op via [email]"
→ EINDE 1E LIJN
🟢 AFRONDING 1e lijn
Sluit case in Intercom
  • Klantnaam toevoegen
  • Email adres
  • Status: Card Issue / Doorverwezen naar 2e lijn
  • Kanaal: IKEA / KPN
  • Actie: Klant geïnformeerd
✅ FLOW EINDIGT (1E LIJN)
Flow 3 – Kaart Wijzigen / Annuleren
🟢 1. START 1e lijn
Mail binnen:
"Kaart per ongeluk gekozen / niet meer gewenst"
🟢 2. CHECK ONTGRENDELING + DETAILS 1e lijn
Vraag naar:
  • ✓ Giffy code
  • ✓ Welke brand (bijv. Bol.com, Zalando)
  • ✓ Is de kaart al ontgrendeld?
➜ ✅ Kaart = ONTGRENDELD
❌ Geen wijziging mogelijk
→ Informeer klant: "Helaas kunnen we een ontgrendelde kaart niet meer wijzigen"
→ EINDE - Sluit case
➜ ❌ Kaart = NIET ONTGRENDELD
✅ Wijziging mogelijk → Ga naar stap 3
🟢 3. ZET IN INTERCOM 1e lijn
Registreer in Intercom:
  • Giffy code
  • Brand
  • Gewenste wijziging
  • Klantgegevens
→ Bevestig klant: "We nemen binnen 1 uur contact op"
→ EINDE 1E LIJN
⚡ OVERDRACHT 1E → 2E LIJN
1e lijn: Ticket aangemaakt
2e lijn: Vervolgt met blokkering →
🔵 4. CONTACT CEES 2e lijn
Verzoek: Team Coda blokkeer ontgrendelmail
  • Verstrek Giffy code
  • Verstrek klantgegevens
🔵 5. BEVESTIG BLOKKERING 2e lijn
Wacht op bevestiging Cees
➜ ⏳ Nog niet geblokkeerd
Wachten...
➜ ✅ Geblokkeerd
Ga naar stap 6
🔵 6. KIES OPLOSSING 2e lijn
Bespreek met klant:
  • Optie 1: Nieuwe kaart versturen
  • OF
  • Optie 2: Restitutie via Benify
🟢 AFRONDING
Sluit case in Intercom
  • Status: Omgezet/Terugbetaald
  • Interne notitie
  • Gekozen oplossing
✅ FLOW EINDIGT
Flow 4 – Haskoning Special Flow
🔵 1. START 2e lijn only
Mail binnen van Haskoning
(Kunnen niet online zelf bestellen - alleen 2e lijn)
🔵 2. CHECK INFO 2e lijn
Mail moet bevatten:
  • Giftcode
  • Gewenste kaart
  • Waarde
➜ ❌ Info ontbreekt
Vraag op via Intercom/email
➜ ✅ Info compleet
Ga naar stap 3
🔵 3. CHECK TRADE PORTAL 2e lijn
Giffy Portal: Heeft code juiste waarde?
➜ ❌ Klopt niet
Escalatie (technisch)
➜ ✅ Klopt wel
Ga naar stap 4
🔵 4. BLOKKEER KAART 2e lijn
Kaart blokkeren in systeem
🔵 5. GO GIFT SHEET 2e lijn
Handmatig invullen:
  • Brand (Bol.com)
  • Waarde (€)
  • Code (Giffy)
🔵 6. INTERCOM UPDATE 2e lijn
Hashtag toevoegen:
#kaart-komt-eraan
🔵 7. EIND VAN DAG 2e lijn
Auto-verzending via GoGift OF Bamboe Portal
🟢 AFRONDING
Sluit case in Intercom
  • Status: Verzonden
  • Interne notitie
✅ FLOW EINDIGT

🔵 2e Lijn (Specialisten) - Technische afhandeling
